# Issue tracker

This repository tracks engineering work in GitHub Issues for `HarshdipSaha/cloudinary4eco`.

- Create feature and bug issues with `gh issue create`.
- Use GitHub pull requests for implementation and review.
- Link child issues to their parent in the issue body and comments.
- Record blockers explicitly in each issue and PR.
- Register every PR created in a T3 thread with that thread's `link_pull_request` tool.
